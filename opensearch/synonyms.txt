# Synonyms for the OpenSearch keyword (BM25) half of hybrid search.
#
# WHY THIS FILE EXISTS. Sellers type the short form; Amazon policy spells it
# out. "my LSR is bad" and "Late Shipment Rate" share no tokens, so word
# matching scores them as unrelated and the keyword half of hybrid search
# contributes nothing on exactly the queries the demo runs on.
#
# Solr format, for the synonym_graph token filter, applied at SEARCH time (not
# index time) so the list can change without re-indexing.
# Comma-separated terms on a line are all equivalent.

# --- performance metrics (the four the demo leans on) ---
lsr, late shipment rate, late shipments, shipping late
odr, order defect rate, order defects
vtr, valid tracking rate, valid tracking, tracking rate
cr, cancellation rate, cancellations, cancelled orders
otdr, on-time delivery rate, on time delivery rate, late deliveries
ahr, account health rating, account health
